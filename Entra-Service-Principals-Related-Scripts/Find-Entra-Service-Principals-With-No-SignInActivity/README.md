<html> <h1>Find Entra Service Principals With No Sign-In Activity</h1> <p> This script helps administrators identify <b>Microsoft Entra Service Principals with no sign-in activity</b> within the last 30 days using Microsoft Graph PowerShell. </p> <hr> <h2>📌 Overview</h2> <p> Unused or inactive Service Principals can represent governance and security risks if left unreviewed. This script identifies Service Principals that have not generated sign-in activity during a specified timeframe. </p> <p>This script enables you to:</p> <ul> <li>Identify inactive Service Principals</li> <li>Detect unused enterprise applications</li> <li>Support cleanup and governance activities</li> <li>Reduce attack surface by reviewing inactive identities</li> </ul> <hr> <h2>🚀 Features</h2> <ul> <li>Fetches all Service Principals in the tenant</li> <li>Retrieves sign-in logs for the last 30 days</li> <li>Identifies Service Principals with no activity</li> <li>Excludes
