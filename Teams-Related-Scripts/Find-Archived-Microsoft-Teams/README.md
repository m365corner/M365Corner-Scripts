<html> <h1>Automate Archived Microsoft Teams Reporting</h1> <p> This script helps administrators automate reporting for <b>archived Microsoft Teams</b> using Microsoft Graph PowerShell. </p> <hr> <h2>📌 Overview</h2> <p> Archived Teams often remain in the environment long after active usage ends. Regular reporting helps administrators review ownership, membership, guest access, and governance posture of archived Teams. </p> <p>This script enables you to:</p> <ul> <li>Identify archived Microsoft Teams</li> <li>Collect owner and membership information</li> <li>Track guest user presence</li> <li>Export governance reports to CSV</li> <li>Email reports automatically to administrators</li> </ul> <hr> <h2>🚀 Features</h2> <ul> <li>Retrieves all Teams-enabled Microsoft 365 groups</li> <li>Filters only archived Teams</li> <li>Captures Team ownership details</li> <li>Counts members and guest users</li> <li>Exports report to CSV</li> <li>Sends automated HTML email with report attachment</li> <li>Includes preview of archived Teams in email body</li> </ul> <hr> <h2>🛠 Prerequisites</h2> <ul> <li>Microsoft Graph PowerShell module</li> <li>Required permissions: <ul> <li><code>Group.Read.All</code></li> <li><code>User.Read.All</code></li> <li><code>Mail.Send</code></li> </ul> </li> </ul> <p>Connect using:</p> <pre> Connect-MgGraph -Scopes "Group.Read.All","User.Read.All","Mail.Send" </pre> <hr> <h2>📂 Files Included</h2> <ul>
